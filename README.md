# Digital Calculator in C / C++

A simple console-based digital calculator built using C / C++.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## How to Compile & Run
1. Open terminal or command prompt.
2. Compile:
   - For C: `gcc calculator.c -o calculator`
   - For C++: `g++ calculator.cpp -o calculator`
3. Run:
   - `./calculator`
